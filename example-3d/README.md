# Original silent 3D asset demo

12 seconds, 1280×720, 30 fps, H.264; **no audio stream**. This is a portable asset
smoke test, not a narrated explainer, historical reconstruction or book chapter.

[MP4](preview/kit.mp4) · [encoded contact sheet](preview/contact.jpg) ·
[technical/browser proof](preview/verification.json) ·
[fresh staged-source replay](preview/replay.json) · [rights/security check scope](preview/audit.json)

Three hard-cut shots: lion/fox/two wolves walking; a procedural house with two fire
and two smoke atlases; a person turning and walking away. The same camera is held
throughout each shot. All artwork is generated by the included code except Unity's
four CC0 textures. No private chapter audio, text or video is required.

## Rebuild from the repository root

Node >=22.12.0, system Chromium (or Chrome), ffmpeg and ffprobe are required.
No TTS/API key or paid generation call is used.

```bash
npm ci --ignore-scripts
npm test
npm run verify:assets
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
CHROMIUM_PATH=/usr/bin/chromium npm run demo:3d
```

CHROMIUM_PATH is a local executable path, not a credential. On another system set it
to the installed Chromium/Chrome binary. Browser launches with sandbox enabled by
default; use `--no-sandbox` **only** in an isolated renderer where sandbox support is
unavailable. This switch is not a recommendation for everyday browsing.

The script refuses to overwrite an existing master. New renders/reports go to ignored
`out/`; committed `preview/` files are deliberately selected derivatives, not frames
from an HTML preview. Browser proof tests reversed seeks, different pixels between
shots and camera immutability. It does not guarantee pixel identity across GPUs/OSes.

Full rendering also probes/counts and decodes the MP4, extracts the contact sheet and
writes its actual SHA256. The contact sheet covers sampled encoded frames, not every
frame or narration sync. Unit/bounds checks and a sampled visual review are different.
