# Native hybrid reference patterns

This guide summarizes reusable visual patterns from four chapter-length explainers
of Machiavelli's *The Prince*. The actual videos and private production evidence
are not distributed in this repository. A local installation may maintain a separate
viewing index with exact master hashes, measured time ranges and access-controlled links.
A reference demonstrates a technique; it is not a blanket source/visual/listening PASS.

## Pick one pattern, not a whole film

- **Chapter 15 — compact abstract conditions:** use direct concept labels and explicit
  conditions instead of making every sentence into character acting. Preserve negation:
  “without X, Y is difficult” must not become “X makes Y difficult.”
- **Chapter 17 — concrete case to abstract relation:** stage an event and its outcome;
  switch to concise labelled links when explaining an abstract obligation or anticipated
  consequence. Attribute judgments to the author, not to universal empirical fact.
- **Chapter 18 — distinct concrete roles and coequal groups:** identify what each animal
  or object does, rather than placing familiar symbols beside an unrelated caption.
  Equal-status list items must share a group before common branches apply.
- **Chapter 25 — flow, preparation and residual risk:** show a continuous inlet, turn
  and outlet. Separate ordinary drainage from landward overflow. Use a held overview
  and an intentional close-up cut, not camera tracking. Treat the geometry as a kinematic
  metaphor, not a fluid solver, measured hazard model or success guarantee.

## Use a private reference responsibly

1. Resolve the exact master revision and its measured timeline before quoting a timecode.
2. Select one relevant excerpt and identify its claim, visual mechanism and known defects.
3. Reuse the generic helper, not the old chapter's narration, voice or approval records.
4. Test only the new claim's required phases. Do not reopen every reference film for review.
5. Record partial findings and omitted checks separately. User aesthetic approval does
   not retroactively run human listening, continuous-action or source-fidelity checks.

Do not package private videos, narration, source scans, local paths or credentials when
sharing a skill. A new public moving demo is a separately scoped deliverable, not a reason
to rerender a completed private chapter.
