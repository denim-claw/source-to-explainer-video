# Production discipline — preserve choices, cost and review scope

## Model identity is not reasoning effort

- Treat model/provider and reasoning effort as independent settings. An effort-only
  request changes only effort; preserve the approved model, including its exact ID.
  If Sol is approved, keep Sol. Do not silently substitute Astra or another model to
  satisfy an effort label, launch a worker or claim a stronger review.
- Pass explicit model and effort arguments to workers, verify their actual launch
  metadata before paid work, and stop on mismatch. Do not change global/profile defaults.
- Record requested effort, documented provider mapping and observed wire setting
  separately. An accepted CLI flag is not proof of backend support or absence of fallback.

## Spend on the change, not on repeated preparation

- Inventory source mapping, approved narration, original audio, measured timing, assets,
  completed shots and QA before synthesis or rendering. Reuse matching assets by hashes
  and provenance; missing credentials must not prevent reuse or technical checks.
- For a visual-only comparison, hold source, narration, original audio, duration and
  essential information constant. Record reused/new steps and unavoidable differences.
  Do not regenerate speech to fix layout or harmless container metadata differences.
- Define the required claims, sample set, repair scope and spending/review ceiling before
  delegation. Default to one correction pass plus one targeted reinspection. Stop with
  remaining failures and a decision request at the ceiling, rather than silently adding
  reviewers, rerenders or optional realism. Blocking defects still block final approval.
- Reuse inspected evidence only with identical hashes, extraction settings and unit/phase
  mapping. Review changed encoded evidence; never inherit native approval for new pixels.
  Freeze acceptance requirements in advance, not retrospectively to clear a failure.
- Attribute usage by stage; separate input/output, cache reads and external speech/image
  charges. A partial audit is not total project cost or a subscription-quota percentage.

## Name the actual illustration method

- Code-drawn Pillow illustrations are procedural raster art. Recognizable people/cities
  can be drawn this way; that does not make them SVG artwork or image-generation output.
- An SVG asset is an actual vector document with provenance. Rasterizing it through
  CairoSVG/Pillow does not change its authored origin; merely drawing shapes is not SVG.
- Image generation means a real image-generation tool/model call and resulting asset,
  with tool/model, prompt, rights and output provenance recorded. Do not claim it ran
  because a renderer made pictures. Reuse approved imagery before another paid call.
- Record creation method separately from visual style and compositing engine. If a
  requested method cannot run, disclose the blocker; do not silently substitute another.

## Scope and evidence remain separate

- A later 'one chapter first; I will review' instruction overrides series-wide momentum.
  Complete only that selected chapter, preserve old masters and hold all others until
  explicit user review authorizes continuation. A successful render is not that approval.
- Route each claim by educational purpose: recognizable actors/actions for unfamiliar
  concrete cases, concise diagrams for classifications/abstract relations. Avoid both
  boxes-only storytelling and decorative illustration; link concrete and abstract states.
- Separate playback/readability, source fidelity, aesthetic preference and learner
  performance. Without a learning test, improvement remains a design hypothesis.

## Sanitized public sync

- Inspect destination, remotes and dirty state first; use an explicit documentation-file
  allowlist rather than recursive skill copying. Preserve public defaults, rights gates
  and provider-specific TTS instructions instead of overwriting them from a local skill.
- Export generic procedures and relevant sanitized references only. Exclude private local
  paths, book text, EPUBs, narration/audio, new production videos, usage/token audits,
  credentials and protected links. Leave separately cleared existing media untouched.
- Run tests, diff checks and a staged-content privacy scan; stage only named paths,
  preserve unrelated edits, then verify the pushed branch SHA with remote readback.
